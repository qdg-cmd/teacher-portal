# 🏫 선생님의 교무실 포털 (Teacher's Web Portal)

선생님께서 개발 및 배포하신 여러 깃허브 웹 앱들을 모바일과 PC에서 한곳에 모아 편리하게 사용할 수 있는 **교무실 테마 웹 포털 런처**입니다.

---

## 📌 중학생도 따라 할 수 있는 4단계 설치 방법

### 1단계: 깃허브(GitHub)에 새 저장소 만들기
1. 인터넷 브라우저에서 **[GitHub](https://github.com)**에 로그인합니다.
2. 우측 상단의 **`+`** 버튼을 누르고 **`New repository`**를 클릭합니다.
3. **Repository name**에 반드시 **`내아이디.github.io`** 라고 적습니다.  
   *(예: 내 깃허브 아이디가 `teacher-kim`이라면 `teacher-kim.github.io` 라고 적어야 합니다!)*
4. **Public**이 선택되어 있는지 확인하고, 하단의 초록색 **`Create repository`** 버튼을 누릅니다.

---

### 2단계: 파일 4개 올리기 (복사 & 붙여넣기)
방금 만든 저장소 화면에서 **`Add file`** $\rightarrow$ **`Create new file`**을 눌러 아래 4개의 파일을 각각 만듭니다:

1. **`index.html`**
   - 파일 이름 칸에 `index.html` 입력
   - 이 폴더에 있는 `index.html` 파일의 내용을 전부 복사(Ctrl+A $\rightarrow$ Ctrl+C)해서 붙여넣기(Ctrl+V)
   - 아래 초록색 **Commit changes** 버튼 클릭

2. **`apps.json`**
   - 파일 이름 칸에 `apps.json` 입력
   - 이 폴더의 `apps.json` 내용 붙여넣기
   - **Commit changes** 버튼 클릭

3. **`manifest.json`**
   - 파일 이름 칸에 `manifest.json` 입력
   - 이 폴더의 `manifest.json` 내용 붙여넣기
   - **Commit changes** 버튼 클릭

4. **`sw.js`**
   - 파일 이름 칸에 `sw.js` 입력
   - 이 폴더의 `sw.js` 내용 붙여넣기
   - **Commit changes** 버튼 클릭

---

### 3단계: 웹사이트 켜기 (GitHub Pages 설정)
1. 저장소 상단 메뉴에서 **`Settings` (톱니바퀴)** 클릭
2. 왼쪽 메뉴에서 **`Pages`** 클릭
3. **Build and deployment** 항목의 **Branch**를 `None`에서 **`main`**으로 바꾸고 **`Save`** 클릭
4. 1~2분 정도 기다린 후 새로고침하면 상단에 **`Your site is live at https://내아이디.github.io/`** 라는 파란색 주소가 뜹니다!
5. 그 주소를 누르면 선생님만의 교무실 포털이 열립니다. 🎉

---

## ✏️ 새로운 웹 앱 추가하는 초간단 방법 (복사 & 붙여넣기)

`apps.json` 파일 안에 선생님을 위한 **복사용 템플릿**과 **60개의 추천 이모지**가 포함되어 있습니다:

1. 깃허브 저장소에서 **`apps.json`** 파일을 클릭하고 우측 상단의 **연필 아이콘(Edit this file)**을 누릅니다.
2. 파일 상단에 있는 아래 템플릿을 복사합니다:
```json
{
  "id": "app-07",
  "title": "웹 앱 이름",
  "url": "https://내아이디.github.io/내앱이름/",
  "icon": "🪑",
  "category": "수업 도구",
  "description": "웹 앱에 대한 간단한 한 줄 설명",
  "badge": "신규"
}
```
3. 대괄호 `[ ... ]` 안쪽 맨 마지막 항목 뒤에 **쉼표(,)**를 찍고 템플릿을 붙여넣습니다.
4. 파일 하단에 정리된 **이모지 모음(60선)**에서 마음에 드는 아이콘을 복사해 `"icon"`에 넣습니다.
5. 하단의 초록색 **Commit changes** 버튼을 누르면 스마트폰과 PC에 즉시 반영됩니다!

---

## 💡 주요 사용법 & 꿀팁

* **앱 실행**: 카드(레이아웃 박스) 어디든 클릭하면 해당 웹 앱이 새 탭으로 바로 실행됩니다.
* **⭐ 상단 고정(즐겨찾기)**: 카드 우측 상단의 별표(⭐)를 누르면 자주 쓰는 앱이 맨 위로 올라옵니다.
* **스마트폰/PC 앱 설치 (PWA)**: 브라우저 메뉴의 **[홈 화면에 추가]** 또는 주소창의 **[앱 설치]**를 누르면 바탕화면에 진짜 앱처럼 설치됩니다!
